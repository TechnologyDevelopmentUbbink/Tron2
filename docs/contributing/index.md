## Before submitting changes

- [ ] All technical claims have a suitable classification.
- [ ] Sources and applicable versions are recorded.
- [ ] Sensitive and restricted information has been removed.
- [ ] Links and images work in the local preview.
- [ ] `python -m mkdocs build --strict` succeeds.
