# Adding Images

Store published images under `docs/assets/images/`. Use subdirectories when a section needs several related files.

## File preparation

- Use descriptive lowercase filenames with hyphens.
- Do not use spaces in filenames.
- Remove credentials, internal addresses, personal data, and other sensitive information from screenshots.
- Prefer PNG for screenshots and SVG where appropriate for diagrams.
- Crop and compress images; avoid uploading unnecessarily large files.
- Confirm that the image can be redistributed.

## Add an image

Use meaningful alt text that explains the image's purpose:

```markdown
![Descriptive view of the relevant interface](../assets/images/example-view.png)
```

Adjust the relative path for the page's location. Preview the page at narrow and wide window sizes and verify that text remains readable.
