# Source documents

This directory is reserved for original manuals and working material used while preparing the TRON 2 documentation. Do not add actual source manuals until their handling and redistribution permissions have been reviewed.

!!! warning "Check before adding files"

    Files placed here are **not automatically published by MkDocs**, but they **may still be committed to Git**. Check every document for confidentiality, copyright, licensing, and redistribution restrictions before adding it. Do not store credentials, access tokens, internal network details, or sensitive Ubbink information here.

Published website content belongs under `docs/`. Record the title, version, language, and relevant page or section when extracting information from a source document.
